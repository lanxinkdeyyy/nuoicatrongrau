# Nuôi Cá Trồng Rau

Game nông trại dễ thương chơi trên trình duyệt: trồng rau, nuôi cá, nuôi gà vịt, câu cá, kết bạn bằng ID, hẹn hò, kết hôn và trang trí nhà.

Dữ liệu người chơi lưu trên Supabase (bảng `ncr_docs`). Chơi tại: https://lanxinkdeyyy.github.io/nuoicatrongrau/

Chạy `supabase-setup.sql` một lần trong Supabase SQL Editor trước khi chơi.
